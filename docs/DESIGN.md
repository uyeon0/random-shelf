> 상태: 확정된 디자인 결정의 구현 기준. 14장의 `미확정` 항목은 확정값으로 취급하지 않는다.  
> 적용 범위: 메인 단일 화면(`/`, HTML), 가로 책 룰렛, 선정 책 상세 모달, 필터, 상태 화면, 푸터.

아래의 색상, 글꼴, 수치, 문구, 동작은 **RANDOM SHELF에서 확정한 자체 결정값**이다. 참고 사이트에서 측정하거나 그대로 옮긴 값이 아니다. 참고 문서인 클래스로 `DESIGN.md`는 문서의 구조와 상세도만 참고했다. 그 문서의 브랜드, 색상, 컴포넌트, 문구는 적용하지 않는다.

## 1. 콘셉트와 화면 원칙

**Editorial Minimal 70% + Playful Modern 30%.** 넓은 여백, 진한 괘선과 강한 글자 위계가 바탕이고, 재미는 책을 뽑는 짧은 순간에 집중한다. 책 표지의 색과 형태가 시각적 중심을 만든다.

- 메인은 **룰렛 중심형 단일 화면**이다. 정보와 행동을 룰렛 주변에 간결하게 배치한다.
- 대표 문구 영역은 **왼쪽 정렬 에디토리얼 그리드**다. 데스크톱에서는 대표 제목을 왼쪽 열(7)에 두 줄로 놓고, 설명·필터 칩·칩 설명을 오른쪽 열(5)에 모아 제목 아래선에 맞춘다. 모바일에서는 같은 순서로 왼쪽 정렬해 쌓는다. 가운데 대칭 배치는 랜딩 페이지처럼 보여 에디토리얼 인상을 약하게 했다.
- `책 한 권 뽑기`는 룰렛 가운데 눈금과 이어지도록 가운데에 둔다.
- 상단 왼쪽에는 `RANDOM SHELF` 로고만 둔다. 다른 메뉴나 내비게이션은 두지 않는다.
- 화면 맨 아래에는 데이터 출처와 프로젝트 정보를 담은 푸터를 둔다(8.4).
- 상품 카드 그리드, 상거래 요소, 책 표지 위 장식, 과도한 그림자는 추가하지 않는다.
- 제목과 설명은 정해진 문구를 쓴다. 책이 선정되면 화면을 이동시키지 않고 중앙 상세 모달을 연다.

- 처음 정했던 `#242424`, `#E76F51`(코랄), `#666666`, 연회색 괘선 `#DEDEDE`, 연분홍 선택 칩 배경 `#FCEAE5`는 화면을 지나치게 부드럽게 만들어 에디토리얼 인상을 약하게 했다. 그래서 검정에 가까운 글자·괘선과 선명한 주홍 강조색으로 바꿨다.
- 강조색을 일반 크기의 글자색으로 쓰지 않는다. 실제 글자/배경 조합의 WCAG 대비를 점검한다.
- 오류색과 성공색은 쓰지 않는다. 빈 결과와 오류는 문구로 구분한다.
- 브랜드 색상과 책 표지 이미지를 혼동하지 않는다. 표지의 원본 색상은 유지한다.

## 3. 타이포그래피

- **Pretendard** 한 글꼴만 쓴다. 세리프 글꼴은 쓰지 않는다. 제목과 본문의 위계는 글꼴이 아니라 크기·굵기·자간으로 만든다.
- 글꼴은 CDN에서 불러오고, fallback은 `sans-serif`다.

| 단계 | 모바일 | 데스크톱 | 굵기 | 행간 | 주 용도 |
| --- | ---: | ---: | ---: | ---: | --- |
| Display | 40px | 64px | 700 | 1.15 | 메인 대표 제목 (자간 -.03em) |
| Section title | 24px | 32px | 700 | 1.35 | 모달 안 책 제목 (자간 -.02em) |
| Lead | 18px | 24px | 400 | 1.5 | 메인 설명 |
| Body | 16px | 16px | 400 | 1.7 | 사서의 추천 글, 필터 칩, 칩 설명, 버튼 |
| Supporting | 14px | 14px | 400 | 1.5 | 저자·출판 정보, 푸터, `다른 책 만나기`. 모달 라벨과 푸터 라벨은 600 |

- Display는 다른 단계보다 크고 굵게, 행간은 좁게 잡아 작은 설명·라벨과의 위계 차이를 크게 둔다.
- 로고는 14px, 600, 자간 .12em의 작은 라벨이다. 큰 대표 제목과 대비를 만든다.
- 모바일/데스크톱 전환은 1024px 기준이다. 1024px 미만에서는 모바일 값을 쓴다.
- 긴 책 제목은 줄바꿈 가능해야 하며 말줄임으로 서지정보를 잃지 않게 한다.

## 4. 레이아웃과 간격

### 4.1 컨테이너와 반응형

| 구간 | 너비 기준 | 좌우 여백 | 기본 섹션 간격 |
| --- | --- | ---: | ---: |
| 모바일 | 768px 미만 | 20px | 64px |
| 태블릿 | 768px 이상, 1024px 미만 | 32px | 96px |
| 데스크톱 | 1024px 이상 | 48px | 128px |

- 콘텐츠 최대 폭은 **1200px**. 화면이 넓어져도 중앙에 정렬한다.
- 브레이크포인트는 **768px / 1024px**. 레이아웃은 모바일 우선으로 작성한다.
- 룰렛은 화면의 주인공이다. 좁은 화면에서도 수평 배치와 가운데 눈금의 의미를 유지한다.

### 4.2 간격 척도

`4, 8, 12, 16, 24, 32, 48, 64, 96, 128px`의 4px 기반 척도를 사용한다.

| 항목 | 값 |
| --- | ---: |
| 카드 안쪽 여백 | 24px |
| 블록 사이 | 32px |
| 룰렛 표지 사이 | 16px |

### 4.3 메인 화면 세로 간격

| 구간 | 값 |
| --- | --- |
| 헤더 위아래 여백 | 24px |

## 6. 책 표지와 가로 룰렛

### 6.1 표지

- 폭은 1024px 미만에서 **140px**, 1024px 이상에서 **190px**로 고정한다.
- API가 주는 표지 원본은 가로 약 132px라서 데스크톱에서는 약간 흐려진다. 선명도보다 표지의 존재감을 우선해 190px를 쓴다.
- 높이는 `auto`로 원본 비율을 보존한다. 표지를 자르거나 동일 높이로 강제하지 않는다.
- 표지 간격은 **16px**, 배열 기준선은 **하단 정렬**이다.
- 표지 URL이 없거나 로딩에 실패한 책은 룰렛 후보에서 **제외**한다. 임의의 대체 표지를 만들지 않는다.
- 후보를 불러오는 동안에는 `#DEDEDE`, 2:3 비율의 정적 스켈레톤을 보여 준다. 표지는 모두 미리 불러온 뒤 룰렛을 그리므로, 이미지가 늦게 도착해 레이아웃을 미는 일은 없다.

### 6.2 가운데 눈금과 선반 선

- 표지 위로 지나가는 선은 두지 않는다. 룰렛 위·아래 16px 여백에 2px × 12px `--color-accent` 눈금을 두어 가운데 위치를 가리킨다. 1장의 "책 표지 위 장식 금지"를 따른 것이다.
- 표지 하단에 1px `--color-rule` 선반 선을 깐다. 하단 정렬된 표지가 선반 위에 놓인 모습이 된다.

### 6.3 선택 동작

1. `책 한 권 뽑기` 또는 `다른 책 만나기`로 수평 룰렛을 시작한다.
2. 매번 **빠른 시작 → 점진 감속**, 총 **2200ms**로 움직인다.
3. 멈춘 시점에 **가운데 눈금에 걸린 책**을 선정한다. 시각적 중앙과 데이터상 선정 결과는 반드시 일치해야 한다.
4. 정지 직후 선정 책의 **중앙 상세 모달**을 연다.

룰렛에는 최대 20권을 올린다. 후보가 20권보다 적으면 같은 책을 반복해 채우고, 후보가 1권이라도 있으면 룰렛을 돌린다. 재뽑기 때 직전 책을 빼지 않는다. 자세한 후보 구성 규칙은 `기획서.md` 6.1을 따른다. 후보가 없으면 빈 결과 상태로 전환한다. 이동 중 중복 클릭은 중복 실행되지 않게 한다.

## 7. 상세 모달

| 항목 | 값 |
| --- | --- |
| 진입 | 룰렛 정지 직후 중앙에 표시 |
| 전환 | fade + scale, 250ms, `opacity: 0 → 1`, `scale(.96) → 1` |
| 표면 | `--color-surface` |
| 오버레이 | `rgba(0, 0, 0, .45)` |
| 최대 너비 | 800px |
| 모바일 너비 | `calc(100% - 32px)` |
| 최대 높이 | `85dvh` |
| 내부 여백 | 모바일 20px, 데스크톱 32px |
| 콘텐츠 배치 | 데스크톱 좌우(표지 | 정보), 모바일 위아래 |
| 그림자 | `0 8px 32px rgba(0, 0, 0, .12)` |

모달 내용은 **책 표지, 제목, 저자, 출판사, 출판연도, 책 속 한 문장, 사서의 추천 글**로 제한한다. 독서 기간, ISBN 표시 등은 포함하지 않는다. 표지는 비율을 유지한다.

- **사서의 추천 글:** 책 소개 자리에 표시하며, 라벨은 `사서의 추천 글`이다. 추천 글에 들어 있는 저자 소개는 표시하지 않는다.
- **책 속 한 문장:** 서지정보와 추천 글 사이에 `책 속 한 문장` 라벨과 인용 블록으로 보여 준다. 인용문은 16px, 500, 행간 1.5, 자간 -.01em이고, 왼쪽에 2px `--color-accent` 세로줄과 16px 들여쓰기를 둔다. 인용문이 없는 책은 이 칸을 숨긴다.
- **읽기 영역:** 책 속 한 문장과 추천 글은 하나의 읽기 영역으로 묶는다. 데스크톱에서는 추천 글만, 1024px 미만에서는 읽기 영역 전체가 스크롤된다. 모바일에서는 인용이 길면 추천 글 칸이 지나치게 좁아지기 때문이다. 어느 쪽이든 표지·제목·서지정보·버튼은 늘 보이게 둔다. 화면이 아주 낮아 읽기 영역의 최소 높이(96px)도 확보하지 못할 때만 모달 전체가 스크롤된다.
- **외부 링크:** `도서관 검색`(Primary)은 도서관 정보나루, `서점 검색`(Secondary)은 교보문고로 보낸다. 검색어는 책 제목이고, 새 탭으로 연다. URL은 `기획서.md` 7.1을 따른다. 사서추천 원문 페이지(API의 `url` 필드)로 가는 링크는 두지 않는다.
- **재뽑기:** `다른 책 만나기`는 모달 안에 둔다. 누르면 모달을 닫고 같은 필터로 룰렛을 다시 돌린다.
- **닫기:** 오른쪽 위 닫기 버튼(Lucide `x` 24px, 터치 영역 44px)과 `Esc`로 닫는다. 배경 클릭으로는 닫지 않는다.
- **접근성:** `<dialog>`로 구현해 배경 조작을 막는다. 접근 가능한 제목을 연결하고, 열릴 때 닫기 버튼으로 초점을 옮기며, 닫히면 `책 한 권 뽑기`로 초점을 돌린다.

| 형태 | outline chip, 단일 선택 |
| 시각적 높이 | 40px |
| 실제 터치 영역 | 최소 44px |
| 좌우 padding | 16px |
| 글자 | Pretendard 16px |
| radius | 0 |
| 전환 | 150ms |
| 비선택 상태 | 투명 배경, 1px `#111111` 테두리, 글자 `#111111`, hover 배경 `#ECE9E2` |
| 선택 상태 | 배경 `#111111`, 테두리 `#111111`, 글자 `#FAF9F6`, 굵기 600 (반전) |
| 기본 선택 | `아무거나` |

필터 목록은 `아무거나`, `이야기와 문장`, `세상과 사람`, `과학과 기술` 네 개다. 각 필터의 정의와 KDC 매핑은 `기획서.md` 5장을 따른다.

칩 줄 아래 12px에 지금 고른 칩의 설명 문구 한 줄을 16px, `#3D3D3D`, 행간 1.5로 왼쪽 정렬해 보여 준다. 문구는 `기획서.md` 5장에 있다. 칩 그룹은 `aria-describedby`로 이 문구를 연결한다.

칩은 `role="radio"`로 만들고 방향키로 고를 수 있다. 선택 상태는 반전 색과 굵기로 함께 전달해, 색만으로 구분하지 않는다.

### 8.3 로고·아이콘·피드백

- 헤더의 유일한 요소는 좌상단 `RANDOM SHELF` 로고다. 헤더 아래에 1px `--color-rule` 머리선을 둔다.
- 아이콘은 **Lucide outline**, 선 **1.5px**, 크기 **20px 또는 24px**. SVG로 직접 넣는다. UI 아이콘으로 이모지를 쓰지 않는다.
- 로딩은 **정적 스켈레톤**으로 표시한다. 회전·펄스 등 추가 애니메이션을 넣지 않는다.
- 빈 결과와 오류에는 상황을 설명하는 문구와 다시 시도할 수 있는 버튼을 제공한다. 문구와 버튼 라벨은 `기획서.md` 8장을 따른다.

### 8.4 푸터

| 항목 | 값/규칙 |

| 형태 | 판권면(colophon)처럼 `라벨`과 `내용`을 나란히 둔 목록 |

## 9. 인터랙션 상태와 흐름

| 상태 | 화면/행동 |
| --- | --- |
| 초기 | 로고, 대표 제목, 설명, 기본 선택 `아무거나` 필터, 룰렛, `책 한 권 뽑기`, 푸터 |
| 후보 로딩 | 정적 스켈레톤, 진행 상태를 접근성 정보로 전달 |
| 준비 완료 | 정상 표지만 후보로 보이고 CTA 사용 가능 |
| 룰렛 실행 | 2200ms 빠른 시작·점진 감속, 중복 실행 방지 |
| 선정 | 가운데 눈금과 선정 데이터 일치, 즉시 상세 모달 진입 |
| 모달 열림 | 내용과 두 검색 행동, `다른 책 만나기` 표시, 배경 조작 차단 |
| 모달 닫힘 | `책 한 권 뽑기`로 초점 복귀, 재뽑기 가능 |
| 빈 결과 | 안내와 다시 시도 버튼 |
| 요청 오류 | 안내와 다시 시도 버튼 |

`prefers-reduced-motion: reduce` 환경에서는 룰렛이 애니메이션 없이 바로 멈춘 위치로 가고, 모달은 전환 없이 표시된다. 버튼과 칩의 전환도 끈다. 책 선택과 상세 확인은 그대로 할 수 있다.

## 11. 데이터 연동 경계

- 책 데이터 출처는 **문화공공데이터광장 국립세종도서관 사서추천도서 API**다. 데이터 처리 규칙은 `기획서.md` 9장을 따른다.
- API 키는 **Netlify Functions 중계 함수**에서만 쓴다. 클라이언트에 비밀 키를 노출하지 않는다.
- 호출 한도, 페이지 범위, 서지정보 분리 규칙, 표지 URL, 검색 링크는 실제 키와 실제 요청으로 확인했다. 결과는 `자료조사.md` 3장에 있다.

## 13. 접근성 및 디자인 QA 체크리스트

WCAG **2.2 AA 지향**. 아래 항목을 실제 브라우저와 보조기기에서 점검한다.

### 시각·레이아웃

- [ ] 320px 안팎의 좁은 화면부터 768px·1024px 경계와 넓은 화면까지 가로 스크롤이 불필요하게 생기지 않는다.
- [ ] 본문과 보조 글자, 버튼 글자, 칩의 모든 상태, 모달의 글자/배경 대비를 측정한다.
- [ ] 텍스트 200% 확대 및 브라우저 줌에서 제목, 룰렛, 모달, 버튼이 겹치거나 잘리지 않는다.
- [ ] 표지 원본 비율, 0 radius, 하단 정렬, 16px 간격, 실패 표지 제외가 지켜진다.
- [ ] 높이 720~900px 데스크톱 화면에서 `책 한 권 뽑기`가 첫 화면 안에 보인다.

### 조작·동작

- [ ] 모든 버튼과 칩을 키보드로 사용할 수 있고 초점 표시가 분명하다.
- [ ] 칩의 선택 상태가 보조기기에 전달되고 색상만으로 구별되지 않는다.
- [ ] 모달이 열릴 때 초점을 이동시키고 내부에 유지하며, 닫힐 때 `책 한 권 뽑기`로 돌린다.
- [ ] 모달 배경을 키보드와 포인터로 조작할 수 없고, 내용이 길어도 `85dvh` 안에서 읽을 수 있다.
- [ ] 룰렛이 멈출 때마다 가운데 눈금의 책과 실제 선정 책이 일치하고 즉시 상세 모달이 열린다.
- [ ] reduced motion 환경에서도 선택 결과와 상세 정보에 접근할 수 있다.
- [ ] 로딩·빈 결과·오류가 시각적으로 구별되며 상태와 재시도 방법을 보조기기에 전달한다.
- [ ] 터치 칩의 실제 대상 크기가 44px 이상이다.

### 데이터·콘텐츠

- [ ] 배포 환경에서 API 키가 브라우저 코드와 응답에 노출되지 않는다.
- [ ] 책 소개 등 API 제공 텍스트의 누락·길이 초과·특수문자 처리를 확인한다.
- [ ] 모달에는 지정된 서지정보만 표시하며 독서 기간과 ISBN 표시를 추가하지 않는다.
- [ ] 도서관/서점 검색 링크가 책 제목으로 검색 결과를 연다.
