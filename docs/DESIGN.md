# DESIGN.md — RANDOM SHELF 디자인 명세

> 상태: 확정된 디자인 결정의 구현 기준. `미확정`과 `제안값`은 확정 토큰으로 취급하지 않는다.  
> 적용 범위: 메인 단일 화면(`/`, HTML), 가로 책 룰렛, 선정 책 상세 모달, 필터 및 상태 화면.

아래의 색상, 글꼴, 수치, 문구, 동작은 **RANDOM SHELF에서 확정한 자체 결정값**이다. 참고 사이트에서 측정하거나 그대로 옮긴 값이 아니다. 참고 문서인 클래스로 `DESIGN.md`는 문서의 구조와 상세도만 참고했다. 그 문서의 브랜드, 색상, 컴포넌트, 문구는 적용하지 않는다.

## 1. 콘셉트와 화면 원칙

**Editorial Minimal 70% + Playful Modern 30%.** 넓은 여백, 절제된 선과 글자 위계가 바탕이고, 재미는 책을 뽑는 짧은 순간에 집중한다. 책 표지의 색과 형태가 시각적 중심을 만든다.

- 메인은 **룰렛 중심형 단일 화면**이다. 정보와 행동을 룰렛 주변에 간결하게 배치한다.
- 대표 문구 영역은 **왼쪽 정렬 에디토리얼 그리드**다. 데스크톱에서는 대표 제목을 왼쪽 열(7)에 두 줄로 놓고, 설명·필터 칩·칩 설명을 오른쪽 열(5)에 모아 제목 아래선에 맞춘다. 모바일에서는 같은 순서로 왼쪽 정렬해 쌓는다. 가운데 대칭 배치는 랜딩 페이지처럼 보여 에디토리얼 인상을 약하게 했다.
- `책 한 권 뽑기`는 룰렛 가운데 눈금과 이어지도록 가운데에 둔다.
- 상단 왼쪽에는 `RANDOM SHELF` 로고만 둔다. 다른 메뉴나 내비게이션은 이 명세의 확정 범위가 아니다.
- 화면 맨 아래에는 데이터 출처와 프로젝트 정보를 담은 푸터를 둔다(8.4).
- 상품 카드 그리드, 상거래 요소, 책 표지 위 장식, 과도한 그림자는 추가하지 않는다.
- 제목과 설명은 정해진 문구를 쓴다. 책이 선정되면 화면을 이동시키지 않고 중앙 상세 모달을 연다.

## 2. 색상

| 역할 토큰 | 확정값 | 용도 |
| --- | --- | --- |
| `--color-bg` | `#FAF9F6` | 페이지 배경 |
| `--color-text` | `#111111` | 주요 글자, 선택 칩 배경, Primary 버튼 배경 |
| `--color-accent` | `#E4321B` | 강조. 룰렛 가운데 눈금 |
| `--color-text-secondary` | `#3D3D3D` | 보조 설명, 메타 정보 |
| `--color-rule` | `#111111` | 1px 괘선: 헤더 머리선, 선반 선, 칩·버튼 테두리 |
| `--color-border` | `#DEDEDE` | 로딩 스켈레톤 |
| `--color-overlay` | `rgba(0, 0, 0, .45)` | 모달 오버레이 |

- 위 표의 `--color-text`, `--color-accent`, `--color-text-secondary`, `--color-rule`은 2026-10-21 "강한 대비" 시안 값으로, **임시값**이다(14.1). 이전 확정값(`#242424`, `#E76F51`, `#666666`, 괘선 `#DEDEDE`)은 화면을 지나치게 부드럽게 만들어 에디토리얼 인상을 약하게 했다. 연분홍 선택 칩 배경(`#FCEAE5`)은 쓰지 않는다.
- 강조색을 일반 크기의 글자색으로 자동 사용하지 않는다. 실제 글자/배경 조합의 WCAG 대비를 점검한다.
- 오류색, 성공색, hover 색, 비활성색, 모달 표면색은 **미확정**이다. 필요한 경우 구현 전에 별도 결정한다.
- 브랜드 색상과 책 표지 이미지를 혼동하지 않는다. 표지의 원본 색상은 유지한다.

## 3. 타이포그래피

- **Pretendard** 한 글꼴만 쓴다. 메인 제목, 선정된 책 제목, 버튼, 필터, 설명, 서지정보 모두 Pretendard다. 제목과 본문의 위계는 글꼴이 아니라 크기·굵기·자간으로 만든다.
- 글꼴은 CDN에서 불러온다. 로딩 전후의 레이아웃 이동을 확인한다.

| 단계 | 모바일 | 데스크톱 | 굵기 | 행간 | 주 용도 |
| --- | ---: | ---: | ---: | ---: | --- |
| Display | 40px | 64px | 700 | 1.15 | 메인 대표 제목 |
| Page title | 30px | 48px | 600 | 1.3 | 페이지 제목이 필요한 경우 |
| Section title | 24px | 32px | 600 | 1.35 | 섹션 제목 |
| Lead | 18px | 24px | 400 | 1.5 | 메인 설명 |
| Body | 16px | 16px | 400 | 1.7 | 본문, 책 소개, 필터 칩, 칩 설명 |
| Supporting | 14px | 14px | 400 | 1.5 | 저자·출판 정보, 도움말 |

Display는 다른 단계보다 크고 굵게(700), 행간은 좁게(1.15) 잡아 작은 설명·라벨과의 위계 차이를 크게 둔다. 세리프 글꼴 없이 Pretendard 한 글꼴로 에디토리얼 대비를 만들기 위해서다.

태블릿의 중간 글자 크기, 자간, 버튼 글자 굵기, 책 제목의 별도 크기는 **미확정**이다. 위 단계를 임의로 늘리거나 레퍼런스의 수치를 가져오지 않는다. 긴 책 제목은 줄바꿈 가능해야 하며 말줄임으로 서지정보를 잃지 않게 한다.

## 4. 레이아웃과 간격

### 4.1 컨테이너와 반응형

| 구간 | 너비 기준 | 좌우 여백 | 기본 섹션 간격 |
| --- | --- | ---: | ---: |
| 모바일 | 768px 미만 | 20px | 64px |
| 태블릿 | 768px 이상, 1024px 미만 | 32px | 96px |
| 데스크톱 | 1024px 이상 | 48px | 128px |

- 콘텐츠 최대 폭은 **1200px**. 화면이 넓어져도 중앙에 정렬한다.
- 브레이크포인트는 **768px / 1024px**. 레이아웃은 모바일 우선으로 작성한다.
- 룰렛은 화면의 주인공이다. 좁은 화면에서도 수평 배치와 중앙 선택선의 의미를 유지한다.
- 기본 에디토리얼 간격이 너무 커서 실제 콘텐츠 흐름을 해칠 때의 **대안**: 섹션 간격 모바일 48px, 데스크톱 64px. 태블릿 컴팩트 값은 **미확정**이다. 대안을 기본값과 섞어 쓰지 않는다.

### 4.2 간격 척도

`4, 8, 12, 16, 24, 32, 48, 64, 96, 128px`의 4px 기반 척도를 사용한다.

| 항목 | 기본 | 명시된 대안 |
| --- | ---: | ---: |
| 카드 안쪽 여백 | 24px | 16px |
| 블록 사이 | 32px | 24px |
| 룰렛 표지 사이 | 16px | 없음 |

대안은 조밀한 화면이 필요한 경우의 선택지이며, 확정 기본값을 대체한 결정은 아니다.

## 5. 형태, 선, 그림자

| 항목 | 확정값 |
| --- | --- |
| 기본 모서리 | 0 (임시값, 14.1) |
| 버튼 모서리 대안 | 8px |
| 카드 모서리 대안 | 12px |
| 책 표지 모서리 | 0 |
| 일반 테두리 | 1px 중심 |
| 일반 카드 그림자 | 없음 |
| 선정된 책 표지 그림자 | 약한 그림자, **수치 미정** |
| 모달 그림자 | `0 8px 32px rgba(0, 0, 0, .12)` |

버튼과 카드의 8px·12px는 **대안**이며 기본은 0이다. 각진 모서리가 인쇄 지면에 가까워 4px에서 0으로 바꿨다. 선정 표지의 그림자 수치를 임의 토큰으로 고정하지 않는다.

## 6. 책 표지와 가로 룰렛

### 6.1 표지

- 폭은 모바일 **140px**, 데스크톱 **190px**로 고정한다. 태블릿 폭은 **미확정**이며, 구현은 1024px 미만에서 모바일 값을 쓴다.
- API가 주는 표지 원본은 가로 약 132px라서 데스크톱에서는 약간 흐려진다. 선명도보다 표지의 존재감을 우선해 190px를 유지한다.
- 높이는 `auto`로 원본 비율을 보존한다. 표지를 자르거나 동일 높이로 강제하지 않는다.
- 표지 간격은 **16px**, 배열 기준선은 **하단 정렬**이다.
- 표지 URL이 없거나 로딩에 실패한 책은 룰렛 후보에서 **제외**한다. 임의의 대체 표지를 만들지 않는다.
- 표지가 아직 로딩 중인 동안에는 정적 스켈레톤을 쓴다. 완료된 이미지의 치수가 레이아웃을 밀지 않도록 후보의 비율 정보를 활용할 수 있는지 확인한다.

### 6.2 선택 동작

1. `책 한 권 뽑기` 또는 재뽑기 동작으로 수평 룰렛을 시작한다.
2. 매번 **빠른 시작 → 점진 감속**, 총 **2200ms**로 움직인다.
3. 멈춘 시점에 **중앙선의 책**을 선정한다. 시각적 중앙과 데이터상 선정 결과는 반드시 일치해야 한다.
4. 정지 직후 선정 책의 **중앙 상세 모달**을 연다.

룰렛에는 최대 20권을 올린다. 후보가 20권보다 적으면 같은 책을 반복해 채우고, 후보가 1권이라도 있으면 룰렛을 돌린다. 재뽑기 때 직전 책을 빼지 않는다. 자세한 후보 구성 규칙은 `기획서.md` 6.1을 따른다. 중앙선의 굵기와 색은 **미확정**이다. API 응답이 부족하거나 표지 실패로 후보가 소진되면 빈 결과 상태로 전환한다. 이동 중 중복 클릭은 중복 실행되지 않게 한다.

## 7. 상세 모달

| 항목 | 확정값 |
| --- | --- |
| 진입 | 룰렛 정지 직후 중앙에 표시 |
| 전환 | fade + scale, 250ms, `opacity: 0 → 1`, `scale(.96) → 1` |
| 오버레이 | `rgba(0, 0, 0, .45)` |
| 최대 너비 | 800px |
| 모바일 너비 | `calc(100% - 32px)` |
| 최대 높이 | `85dvh` |
| 내부 여백 | 모바일 20px, 데스크톱 32px |
| 콘텐츠 배치 | 데스크톱 좌우, 모바일 위아래 |
| 그림자 | `0 8px 32px rgba(0, 0, 0, .12)` |

모달 내용은 **책 표지, 제목, 저자, 출판사, 출판연도, 책 속 한 문장, 사서의 추천 글**로 제한한다. 사서의 추천 글은 책 소개 자리에 표시하며, 화면 라벨은 `사서의 추천 글`이다. 추천 글의 저자 소개는 표시하지 않는다. 독서 기간, ISBN 표시 등은 포함하지 않는다. 책 속 한 문장과 추천 글은 하나의 읽기 영역으로 묶는다. 데스크톱에서는 추천 글만, 모바일(1024px 미만)에서는 읽기 영역 전체가 스크롤된다. 모바일에서는 인용이 길면 추천 글 칸이 지나치게 좁아지기 때문이다. 어느 쪽이든 표지·제목·서지정보·버튼은 늘 보이게 둔다. 표지는 비율을 유지한다.

- **Primary**: `도서관 검색`.
- **Secondary**: `서점 검색`.
- 외부 링크는 위 두 개로 확정한다. 사서추천 원문 페이지(API의 `url` 필드)로 가는 링크는 두지 않는다.
- 재뽑기 버튼 `다른 책 만나기`는 모달 안에 둔다. 누르면 모달을 닫고 같은 필터로 룰렛을 다시 돌린다.
- `도서관 검색`은 도서관 정보나루, `서점 검색`은 교보문고로 보낸다. 검색어는 책 제목이고, 새 탭으로 연다. URL은 `기획서.md` 7.1을 따른다.
- 닫기 수단을 제공하고, `role="dialog"`, 접근 가능한 제목, 열릴 때의 초점 이동, 내부 초점 유지, 닫힐 때 원래 버튼으로 초점 복귀를 구현한다. `Esc` 동작과 배경 클릭 닫기는 실제 사용성 점검 대상이다.

## 8. 컴포넌트 명세

### 8.1 버튼

| 항목 | 값/규칙 |
| --- | --- |
| 기본 높이 | 44px |
| 주요 CTA 높이 | 52px |
| 좌우 padding | 24px |
| 기본 radius | 0 |
| 누름 | `scale(.98)`, 150ms |
| 초점 | 키보드에서 명확히 보이는 focus 표시 |

메인 CTA의 라벨은 `책 한 권 뽑기`, 재뽑기 라벨은 `다른 책 만나기`다. 재뽑기 버튼은 상세 모달 안에 두며, **시각 스타일은 미정**이다. Primary/Secondary는 모달 내 행동의 우선순위를 뜻하며, 배경/글자/테두리 조합은 대비 검증 후 결정한다. 로딩 중 버튼은 중복 실행을 막고 상태를 전달한다. hover, disabled, focus 선의 구체적 색과 굵기는 **미확정**이다.

### 8.2 단일 선택 필터 칩

| 항목 | 확정값 |
| --- | --- |
| 형태 | outline chip, 단일 선택 |
| 시각적 높이 | 40px |
| 실제 터치 영역 | 최소 44px |
| 좌우 padding | 16px |
| 글자 | Pretendard 16px |
| radius | 0 |
| 전환 | 150ms |
| 선택 상태 | 배경 `#111111`, 테두리 `#111111`, 글자 `#FAF9F6`, 굵기 600 (반전) |
| 기본 선택 | `아무거나` |

필터 목록은 `아무거나`, `이야기와 문장`, `세상과 사람`, `과학과 기술` 네 개다. 각 필터의 정의와 KDC 매핑은 `기획서.md` 5장을 따른다.

칩 줄 아래 12px에 지금 고른 칩의 설명 문구 한 줄을 16px, `#3D3D3D`, 행간 1.5로 왼쪽 정렬해 보여 준다. 문구는 `기획서.md` 5장에 있다. 칩 그룹은 `aria-describedby`로 이 문구를 연결한다.

칩은 키보드로 조작할 수 있어야 하고, 선택 상태를 색만으로 전달하지 않는다. 미선택 상태의 정확한 색 조합은 **미확정**이다.

### 8.3 로고·아이콘·피드백

- 헤더의 유일한 요소는 좌상단 `RANDOM SHELF` 로고다. 로고의 도형화, 크기, 자간은 **미확정**이다.
- 아이콘은 **Lucide outline**, 선 **1.5px**, 크기 **20px 또는 24px**. UI 아이콘으로 이모지를 쓰지 않는다.
- 로딩은 **정적 스켈레톤**으로 표시한다. 회전·펄스 등 추가 애니메이션을 기본값으로 넣지 않는다.
- 빈 결과와 오류에는 상황을 설명하는 문구와 다시 시도할 수 있는 버튼을 제공한다. 문구와 버튼 라벨은 `기획서.md` 8장을 따른다.

## 11. 데이터 연동 경계

- 책 데이터 출처는 **문화공공데이터광장 국립세종도서관 사서추천도서 API**로 정한다. 데이터 처리 규칙은 `기획서.md` 9장을 따른다.
- API 키는 **Netlify Functions 중계 함수**에서만 쓴다. 클라이언트에 비밀 키를 노출하지 않는다.
- 호출 제한, 페이지 범위, 서지정보(저자·출판사·출판연도) 분리 규칙, 장애 처리, 이용 조건은 **검증 대상**이다. 검증 전에는 구현 가능하다고 단정하거나 임의 데이터 규칙을 확정하지 않는다.
- 표지 없는 책과 이미지 로딩 실패 책을 제외할 때 충분한 후보가 남는지도 확인한다.
- 서점·도서관 검색 링크의 대상과 검색 방식은 별도 검증 후 정한다.

## 12. CSS 변수와 반응형 적용 기준

아래는 확정값과 2장의 임시 색값을 담은 시작점이다. 그 밖에 아직 정해지지 않은 색이나 동작을 임의 변수로 추가하지 않는다. 나머지 임시값은 14.1에 있다.

```css
:root {
  --color-bg: #FAF9F6;
  --color-text: #111111;
  --color-accent: #E4321B;
  --color-text-secondary: #3D3D3D;
  --color-rule: #111111;
  --color-border: #DEDEDE;
  --color-overlay: rgba(0, 0, 0, .45);

  --font-ui: "Pretendard", sans-serif;

  --container-max: 1200px;
  --page-gutter: 20px;
  --section-gap: 64px;
  --card-padding: 24px;
  --block-gap: 32px;
  --cover-gap: 16px;
  --cover-width: 140px;
  --radius-default: 0;
  --shadow-modal: 0 8px 32px rgba(0, 0, 0, .12);
}

@media (min-width: 768px) {
  :root {
    --page-gutter: 32px;
    --section-gap: 96px;
  }
}

@media (min-width: 1024px) {
  :root {
    --page-gutter: 48px;
    --section-gap: 128px;
    --cover-width: 190px;
  }
}
```

컨테이너는 `width: min(calc(100% - var(--page-gutter) - var(--page-gutter)), var(--container-max))`로 중앙 정렬한다. 모바일/데스크톱 타이포 전환도 1024px 기준으로 적용한다. 태블릿의 폰트·표지 중간값은 별도 결정이 필요하다.

## 13. 접근성 및 디자인 QA 체크리스트

WCAG **2.2 AA 지향**. 아래 항목을 실제 브라우저와 보조기기에서 점검한다.

### 시각·레이아웃

- [ ] 320px 안팎의 좁은 화면부터 768px·1024px 경계와 넓은 화면까지 가로 스크롤이 불필요하게 생기지 않는다.
- [ ] 본문과 보조 글자, 버튼 글자, 칩의 모든 상태, 모달의 글자/배경 대비를 측정한다. 강조색 단독 글자의 사용은 따로 검증한다.
- [ ] 텍스트 200% 확대 및 브라우저 줌에서 제목, 룰렛, 모달, 버튼이 겹치거나 잘리지 않는다.
- [ ] 표지 원본 비율, 0 radius, 하단 정렬, 16px 간격, 실패 표지 제외가 지켜진다.
- [ ] 여백·굵기·행간·최대 폭·모서리·그림자가 이 명세의 기본값과 일치한다.

### 조작·동작

- [ ] 모든 버튼과 칩을 키보드로 사용할 수 있고 초점 표시가 분명하다.
- [ ] 칩의 선택 상태가 보조기기에 전달되고 색상만으로 구별되지 않는다.
- [ ] 모달이 열릴 때 초점을 이동시키고 내부에 유지하며, 닫힐 때 원래 위치로 돌린다.
- [ ] 모달 배경을 키보드와 포인터로 조작할 수 없고, 내용이 길어도 `85dvh` 안에서 읽을 수 있다.
- [ ] 2200ms마다 중앙선의 책과 실제 선정 책이 일치하고 즉시 상세 모달이 열린다.
- [ ] reduced motion 환경에서도 선택 결과와 상세 정보에 접근할 수 있다.
- [ ] 로딩·빈 결과·오류가 시각적으로 구별되며 상태와 재시도 방법을 보조기기에 전달한다.
- [ ] 터치 칩의 실제 대상 크기가 44px 이상이다.

### 데이터·콘텐츠

- [ ] API의 호출 한도·키 보안·표지/추천 글 필드를 실제 문서와 호출 결과로 확인한다.
- [ ] 책 소개 등 API 제공 텍스트의 누락·길이 초과·특수문자 처리를 확인한다.
- [ ] 모달에는 지정된 서지정보만 표시하며 독서 기간과 ISBN 표시를 추가하지 않는다.
- [ ] 도서관/서점 검색 링크의 목적지와 검색어를 확인한 뒤 연결한다.
- [ ] 확정되지 않은 대안값을 기본값으로 오인해 배포하지 않는다.
