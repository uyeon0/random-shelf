# RANDOM SHELF 자료조사

작성일: 2026-10-21

기능과 데이터 규칙은 `기획서.md`에 있다. 이 메모는 그 규칙의 근거가 된 API 문서 확인, 실제 호출, 표본 분석 결과를 담는다.

## 1. 국립세종도서관 사서추천도서 API

### 1.1 공식 문서 확인

[문화공공데이터광장 공식 문서](https://www.culture.go.kr/data/openapi/openapiView.do?id=362)의 요청 URL은 `https://api.kcisa.kr/openapi/service/rest/meta13/getNLSF0401`이다. 문서에 표시된 요청 변수는 필수 `serviceKey`와 선택 `numOfRows`, `pageNo` 세 가지다. 카테고리나 KDC를 지정하는 요청 변수는 문서에 없다. 문서는 `referenceIdentifier`를 썸네일 이미지 식별정보로, `url`을 자원 위치 정보로 설명한다.

### 1.2 인증키 없이 보낸 요청

2026-10-21에 `numOfRows=1&pageNo=1`로 인증키 없이 GET 요청을 보냈다. 서버는 HTTP 401과 `{"message":"Unauthorized","http_status_code":401}`을 반환했다. 따라서 이 시점에는 책 데이터를 새로 조회하지 못했고 현재 총량도 확인하지 못했다. 발급받은 키로 다시 요청해야 한다.

## 2. 이전에 받은 응답 50건 분석

분석 대상은 이전 대화에 첨부된 `붙여넣은 마크다운(2).md`의 응답 50건 전체다. 응답에는 `numOfRows=50`, `pageNo=1`, `totalCount=733`이 기록돼 있다. `733`은 당시 응답의 값이고 현재 총량을 새로 확인한 수치는 아니다. 아래 비율의 분모는 모두 50건이다.

### 2.1 필드 누락률

| 필드 | 누락 | 누락률 | 판단 |
| --- | ---: | ---: | --- |
| `title` | 0 | 0% | 제목 표시 가능 |
| `description` | 0 | 0% | 50건 모두 사서 추천 글 표제 포함 |
| `subjectCategory` | 2 | 4% | 값이 있어도 KDC가 아닌 `추천도서` 등 |
| `subjectKeyword` | 50 | 100% | 필터 근거로 사용 불가 |
| `extent` | 50 | 100% | 쪽수 기준 필터 불가 |
| `referenceIdentifier` | 0 | 0% | 표지 URL 값 존재 |
| `url` | 0 | 0% | 원문 링크 값 존재 |
| `rights` | 8 | 16% | 권리 표시가 필요하면 빈 값 처리 필요 |

`creator`, `regDate`, `collectionDb`, `language`는 50건 모두 값이 있다. `alternativeTitle`, `spatialCoverage`, `temporal`, `person`, `sourceTitle`, `copyrightOthers`, `contributor`는 50건 모두 비어 있다. `creator`는 50건 모두 `누리집`이라 필드 이름과 실제 값의 의미가 다르다.

### 2.2 KDC 추출 결과

각 `description`을 `사서의 추천 글` 앞에서 자르고, 그 구간에서 처음 나오는 `세 자리 숫자[.소수]-연도-번호` 형태의 청구기호를 썼다. 이 규칙으로 50건 모두에서 KDC를 추출했다. 이 표본에서의 결과이며 전체 데이터에서도 같다고 확인하지는 않았다.

| KDC 대분류 | 건수 |
| --- | ---: |
| 100 철학 | 8 |
| 200 종교 | 0 |
| 300 사회과학 | 6 |
| 400 자연과학 | 9 |
| 500 기술과학 | 4 |
| 600 예술 | 3 |
| 700 언어 | 1 |
| 800 문학 | 13 |
| 900 역사 | 6 |

### 2.3 필터별 후보 수

| 필터 | 후보 수 | 50건 대비 |
| --- | ---: | ---: |
| `아무거나` | 50 | 100% |
| `이야기와 문장` | 13 | 26% |
| `세상과 사람` | 20 | 40% |
| `과학과 기술` | 13 | 26% |

세 주제 필터는 서로 겹치지 않고 합쳐서 46건이다. 나머지 4건(8%)은 KDC 600·700이라 `아무거나`에서만 후보가 된다.

### 2.4 표지 URL

- `referenceIdentifier`는 50건 모두 값이 있고, 정규화한 URL 50개는 모두 서로 다르다.
- 원본 텍스트에는 `http\://`처럼 역슬래시가 들어 있어 URL로 쓰기 전에 제거해야 한다.
- 정규화한 50개 주소는 모두 `http://sejong.nl.go.kr/comm/getImage.do` 형태다.
- 대표 주소 1건을 `https://`로 요청해 HTTP 200, `image/png` 응답을 확인했다. 나머지 49개는 확인하지 않았다.

## 3. 발급받은 키로 받은 전체 데이터 확인

2026-10-21에 중계 함수(`netlify/functions/books.mjs`)를 `netlify dev`로 띄우고 발급받은 키로 요청했다.

### 3.1 응답과 건수

- 응답은 JSON이고 `response.header.resultCode`가 `0000`이다.
- `numOfRows=100`으로 한 번에 100건을 받을 수 있다.
- 현재 `totalCount`는 733이다. `numOfRows=100`이면 1~7페이지는 100건, 8페이지는 33건이다.
- 8페이지를 모두 받아 733건을 모았고, 제목은 733개가 모두 서로 다르다.

### 3.2 서지정보 형식

`description`의 서지정보는 대부분 `제목 저자 지음 ｜ 역자 옮김 ｜ 출판사 ｜ 연도 청구기호, 자료실` 형태다. 다만 아래처럼 형식이 섞여 있다.

- 구분자로 전각 `｜`, 반각 `|`, 한글 `ㅣ`, 세미콜론, 쉼표를 쓴다. 한 책 안에서 섞어 쓰는 경우도 있다.
- 추천 글 표시가 `사서의 추천 글`, `사서의 추천글`, `사서의 추천`으로 다르다.
- 어린이·청소년 자료는 청구기호 앞에 `아`가 붙는다. 예: `아 813.7-15-984`
- `description`의 제목과 `title` 필드가 띄어쓰기, 문장부호, 앞쪽 괄호, 부제 유무에서 다를 수 있다.
- 저자 앞에 `지은이:`, `저자 :`, `글쓴이:` 같은 머리말이 붙거나, `지음` 같은 역할어가 없는 경우가 있다.

### 3.3 정규식 분리 결과

아래 규칙으로 733건 중 714건(97.4%)에서 제목, 저자, 출판사, 출판연도, KDC, 추천 글을 모두 분리했다.

1. 추천 글 표시(`사서의\s*추천(\s*글)?`) 앞을 서지정보, 뒤를 추천 글로 나눈다.
2. 서지정보에서 `(연도) (아)청구기호` 형태를 찾아 출판연도와 KDC 대분류(청구기호 앞 세 자리)를 얻는다.
3. 그 앞부분을 `|`, `｜`, `ㅣ`, `;`로 나눈다. 이 구분자가 하나도 없으면 쉼표로 나눈다.
4. 첫 조각에서 `title` 필드의 글자(문자·숫자만)를 앞에서부터 맞춰 소비하고, 남은 부분을 저자로 본다. 맞지 않으면 부제를 뗀 제목, 앞쪽 괄호를 뗀 제목으로 다시 맞춘다.
5. 마지막 조각의 마지막 쉼표 뒤를 출판사로 본다.
6. 저자 머리말을 지운다. 저자가 비었거나 HTML 조각이 섞였으면 실패로 본다. `지음` 같은 역할어가 없는 저자는, 쉼표 형식이 아니고 15자 이하일 때만 받아들인다.

분리에 실패한 19건의 원인은 아래와 같다.

| 원인 | 건수 | 예 |
| --- | ---: | --- |
| `description`과 `title`의 제목이 글자 단위로 다름 | 8 | `배개`/`베개`, `유렵`/`유럽`, `心 스틸러`/`심스틸러` |
| 저자 칸에 부제·HTML·특이한 형식이 섞임 | 11 | `size: 12pt;">이영혜 지음`, `글: … ｜ 사진: … ｜ 그림: …` |

남은 오류도 있다. `성일권 감수 마인드큐브`처럼 감수자가 출판사 칸에 붙거나, `이와이 도시노리 지음 최서희 옮김`처럼 역자가 저자 칸에 붙는 책이 일부 있다.

### 3.4 필터별 후보 수

분리에 성공한 714건 기준이다.

| 필터 | 후보 수 |
| --- | ---: |
| `아무거나` | 714 |
| `이야기와 문장` | 188 |
| `세상과 사람` | 292 |
| `과학과 기술` | 164 |

나머지 70건은 KDC 000·600·700이라 `아무거나`에서만 후보가 된다. 100건을 무작위로 받으면 필터별로 평균 20건 넘게 남는다는 계산이 나오지만, 실제 페이지별 분포는 확인하지 않았다.

### 3.5 표지 URL

733건 모두 `referenceIdentifier`에 `sejong.nl.go.kr/comm/getImage.do` 주소가 있다. 37건 간격으로 고른 20건을 `https://`로 요청해 20건 모두 이미지 응답을 받았다.

## 4. 검토했지만 쓰지 않은 API: 국립중앙도서관 ISBN 서지정보

[ISBN 서지정보 API 활용방법](https://www.nl.go.kr/NL/contents/N31101030500.do)과 [Open API 이용안내](https://www.nl.go.kr/NL/contents/N31101010000.do)를 2026-10-21에 확인했다. 인증키로 실제 호출하지는 않았다.

- 검색 URL은 `https://www.nl.go.kr/seoji/SearchApi.do`이고 필수 요청 변수는 `cert_key`, `result_style`, `page_no`, `page_size`다.
- 안내 문서에 적힌 응답 항목에는 제목, 저자, ISBN, 출판사, 페이지, 표지 이미지 URL, 책소개가 있다. 서비스에 따라 제공 필드가 제한될 수 있다고 안내한다.
- `PUBLISH_PREDATE`는 공식 문서상 출판예정일이라 실제 출판연도로 단정할 수 없다.
- 분야나 페이지 수로 거르는 요청 변수는 확인하지 못했다.
- 인증키를 받으려면 국립중앙도서관 회원가입, 인증키 신청, 담당자 승인을 거쳐야 한다.
